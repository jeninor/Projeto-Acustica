# Pacote de relatório — CF2 Directivity Analyzer & Summarizer (v0.7)

Relatório técnico em português sobre a caracterização de diretividade por banda de frequência a partir de arquivos CF2.

## Leitura recomendada

1. Abra `RELATORIO_TECNICO_CF2_v07_PTBR.md` em um visualizador Markdown com suporte a imagens relativas.
2. Consulte `exemplos/FICHA_BOSCH_PTBR.md` para uma síntese ilustrativa do modelo Bosch.
3. Utilize `exemplos/bosch_metricas_21_bandas.csv` para conferir numericamente todas as 21 bandas do exemplo.
4. Se desejar executar o software, extraia `codigo/cf2_directivity_analyzer_summarizer_v07_codigo.zip` e siga o `README.md` interno desse projeto.

As duas imagens no diretório `figuras/` são opcionais, reutilizadas de análises anteriores, e não representam nova validação externa. A geração dos metadados dispensa gráficos.

**Escopo:** análise e resumo, sem seleção de alto-falantes para cenários.
